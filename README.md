## 🧠 Inhalte (bisher)

- Logikprogrammierung: beschreiben **was** gelten soll, nicht **wie** — gut für Planungs- und Zuordnungsprobleme
- Reihenfolge der Regeln ändert die Bedeutung nicht
- Fakten, Regeln, Variablen, Negation
- **Closed-World-Annahme**: Was nicht ableitbar ist, gilt als falsch
- Beispiel: Sudoku als Constraints modellieren, Solver findet Lösungen
- Performance hängt von guter Modellierung ab — unnötige Möglichkeiten früh ausschließen
